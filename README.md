# 봄바나나 폭탄 박스

봄바나나 게임에서 눈을 가린 원숭이가 조작하는 폭탄 박스를 아두이노로 만든 장치입니다.
원숭이는 불빛을 볼 수 없기 때문에, 설명서를 가진 친구가 불빛 색을 보고 어떤 선을 자를지 알려줘야 합니다.

## 해제 규칙

폭탄이 작동하면 LED 3개 중 하나가 무작위로 켜집니다. 불빛 색에 맞는 선 하나만 자르면 해제, 다른 선을 자르면 폭발합니다.

| 불빛 | 자를 선 |
|---|---|
| 빨간불 | 노랑 선 |
| 노란불 | 빨강 선 |
| 초록불 | 파랑 선 |

## 진행 순서

1. 전원을 켜면 LED 3개가 차례로 한 번씩 켜집니다 (점검).
2. 선 3개가 모두 꽂힐 때까지 기다립니다. 덜 꽂힌 선은 시리얼 모니터에 `끊김`으로 표시됩니다.
3. 선이 모두 연결되면 폭탄이 작동하고, LED 하나가 무작위로 켜집니다.
4. 처음 잘린 선으로 결과가 정해지고, 시리얼 모니터에 `해제 성공!` 또는 `펑! 폭발!`이 표시됩니다.
5. 다시 하려면 선을 모두 꽂고 보드의 RESET 버튼을 누릅니다.

## 부품

| 부품 | 수량 |
|---|---|
| 아두이노 우노 호환 보드 | 1 |
| 미니 브레드보드 | 1 |
| 점퍼선 | 약 12 |
| LED (빨강, 노랑, 초록) | 각 1 |
| 저항 220Ω 또는 330Ω | 1 |

## 배선

| 핀 | 연결 |
|---|---|
| 2, 3, 4 | 빨강, 파랑, 노랑 선 (반대쪽은 GND) |
| 9, 10, 11 | 빨강, 노랑, 초록 LED의 긴 다리(+) |
| GND | 브레드보드 GND 세로줄 (선 3개가 함께 사용) |
| 저항 1개 | LED 3개의 짧은 다리(−) 공통 줄과 GND 사이 |
| A5 | 비워둠 (무작위 값 생성용) |
| 0, 1 | 사용하지 않음 (PC 통신용) |

선은 `INPUT_PULLUP`으로 읽기 때문에, 연결되면 LOW, 끊기면 HIGH가 되어 별도 저항 없이 잘림을 감지합니다.
LED는 한 번에 하나만 켜지므로 저항 하나를 3개가 함께 씁니다.

## 실행 방법

1. [Arduino IDE 2.x](https://www.arduino.cc/en/software)를 설치합니다. 호환 보드라면 CH340 드라이버가 필요할 수 있습니다.
2. `bomb_box/bomb_box.ino`를 엽니다.
3. 보드를 **Arduino Uno**, 포트를 연결된 COM 포트로 고르고 업로드합니다.
4. 시리얼 모니터를 열고 속도를 **9600 baud**로 맞춥니다.

## 규칙 바꾸기

`RULE` 배열의 숫자만 바꾸면 됩니다. 순서는 빨간불, 노란불, 초록불이고, 값은 선 번호(0=빨강, 1=파랑, 2=노랑)입니다.

```cpp
const int RULE[] = {2, 0, 1};   // 빨간불→노랑선, 노란불→빨강선, 초록불→파랑선
```

## 앞으로 할 일

- 슬라이드 가변저항(A0)으로 올리고 내리는 조작 추가
- 소리 모듈(부저)을 연결해 폭발하면 삐 소리 내기
- 제한 시간 타이머
- 상자에 넣어 선, LED, 슬라이드만 밖으로 꺼내기
